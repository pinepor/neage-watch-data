プライバシーポリシー

本プライバシーポリシーは、Hirota Yoshitake（以下「開発者」）が提供するiOSアプリ「値上がりウォッチ」（以下「本アプリ」）における個人情報の取り扱いについて説明するものです。

1. 収集する情報

本アプリは以下の情報を収集・利用します。

  • 節約履歴： シミュレーターで記録した節約履歴はお客様のデバイス内のみに保存されます。外部サーバーへの送信は行いません。
  • 購入情報： アプリ内課金（プレミアム）の購入状態はデバイス内に保存されます。Apple のサーバーを通じて検証されます。
  • 値上げデータ： 値上げ情報は GitHub Pages 上に公開されたJSONファイルを取得するものであり、お客様の個人情報は一切含まれません。

2. 情報の利用目的

  • アプリの基本機能の提供（値上げ情報の表示・節約シミュレーター）
  • アプリ内課金の処理（Apple StoreKit）
  • プッシュ通知の送信（プレミアム機能、ユーザーの許可が必要）

3. 第三者への提供

開発者は取得した個人情報を、以下の場合を除き第三者に提供しません。

  • Apple（アプリ内課金処理）: Appleプライバシーポリシー
  • 法令に基づき開示が必要な場合

4. データの保存場所

節約履歴・通知設定などのデータはすべてお客様のデバイス内にのみ保存されます。外部サーバーへの送信は行いません。

5. お子様のプライバシー

本アプリは13歳未満のお子様を対象としていません。13歳未満の方の個人情報を意図的に収集することはありません。

6. プライバシーポリシーの変更

本プライバシーポリシーは予告なく変更される場合があります。変更後はこのページに掲載します。
